# 实验结果（测试集）

指标：P/R/F1/IoU 为阈值 0.5 的像素级指标；ODS/OIS 为最优阈值 F1；clDice 为中心线重叠度；
Frag = 每条真实裂缝被预测成几段（越接近 1 越连续）；Betti0 = 连通域个数误差（越小越好）。
多随机种子时给出 均值±标准差。
